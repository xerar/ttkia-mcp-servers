# Ejemplos

Servidores MCP aportados por compañeros, listos para copiar, adaptar y alojar donde tengas sitio. Cada uno tiene su README con qué hace, qué necesita y quién lo mantiene.

| Ejemplo | Qué hace | Mantiene |
| --- | --- | --- |
| *Todavía ninguno.* | Si tienes uno, [así se aporta](../CONTRIBUTING.md). | |

Todos pasan la misma revisión automática que la [plantilla](../plantilla/): sin secretos ni direcciones internas, arrancan, exigen token y solo publican herramientas de solo lectura.
